# Adobe CX Enterprise Coworker을 사용하여 대화 내보내기

Adobe Experience Platform Query Service 및 Adobe CX Enterprise Coworker을 사용하여 Adobe Brand Concierge 대화를 저장하고 내보내는 방법에 대해 알아봅니다. 이 비디오는 조직에서 데이터 세트 테이블 이름을 찾고, 날짜 범위에 대한 대화 데이터를 요청하고, Data Distiller을 사용할 수 있을 때 CSV를 다운로드하는 방법을 보여 줍니다.

## 이 비디오는 누구의 것입니까?

* Brand Concierge 대화 데이터를 내보내야 하는 개발자

## 비디오 콘텐츠

* Experience Platform에서 대화 데이터 세트를 찾고 해당 테이블 이름 복사
* 동료에게 지정된 날짜 범위에 대한 응답 테이블에서 데이터를 검색하도록 요청
* 비디오에 표시된 CSV 다운로드에 Data Distiller이 필요한 이유를 이해합니다
* PII(개인 식별 정보)가 포함될 수 있는 내보내기를 저장할 때 조직의 데이터 처리 정책을 따르십시오

>[!VIDEO](https://video.tv.adobe.com/v/3504546)

>[!NOTE]
>
> 조직에서 Data Distiller을 사용할 수 없는 경우 동료는 이 비디오에 표시된 CSV 다운로드를 만들 수 없습니다.

설명서는 [Brand Concierge 도움말](../documentation/overview.md)을 참조하세요.
