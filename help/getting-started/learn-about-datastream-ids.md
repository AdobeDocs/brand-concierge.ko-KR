# 데이터 스트림 ID에 대해 알아보기

데이터스트림 ID가 사이트의 웹 SDK 이벤트를 Adobe Experience Platform의 Adobe Brand Concierge에 연결하는 방법에 대해 알아봅니다. ID가 필요한 이유, 데이터를 올바른 샌드박스 및 데이터 세트로 라우팅하는 방법, 팀이 개발, 스테이징 및 프로덕션을 위해 별도의 데이터 스트림을 사용하는 방법에 대해 알아봅니다.

## 이 비디오는 누구의 것입니까?

* Developer
* 제품 관리자
* 솔루션 컨설턴트

## 비디오 콘텐츠

* 웹 SDK 및 Brand Concierge에 데이터 스트림 ID가 필요한 이유
* 데이터스트림이 샌드박스, 데이터 세트, 스키마 및 ID로 이벤트를 라우팅하는 방법
* 팀이 개발, 스테이지 및 프로덕션에 서로 다른 데이터스트림을 사용하는 이유
