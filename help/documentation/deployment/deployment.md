# 컨시어지 배포

배포는 실제 웹 사이트 방문자가 컨시어지를 사용할 수 있도록 합니다. 마케터는 배포 설정을 구성하는 반면, IT 또는 분석 팀은 데이터 스트림 ID를 제공하고 웹 사이트 팀은 웹 사이트에 배포 스크립트를 설치합니다.

배포는 일반적으로 각 사이트에 대해 간단한 1회 구성입니다. 마케터의 입장에서 약 15분 동안 웹 사이트 팀이 스크립트를 설치하는 데 필요한 시간을 계획합니다.

>[!IMPORTANT]
>
>IT 또는 분석 팀과 웹 사이트 팀을 일찍 참여시킵니다. 데이터 스트림 ID를 제공하고 스크립트를 설치하려면 참여해야 하므로 배포가 구현의 마지막 단계로 간주되어서는 안 됩니다.

## 시작하기에 앞서

- IT 또는 분석 팀과 조정하여 데이터 스트림 ID를 얻습니다.
- 웹 사이트 또는 태그 관리자를 담당하는 팀을 식별합니다. 이 문서에서는 이 그룹을 웹 사이트 팀으로 지칭합니다.
- 컨시어지를 기존 페이지에 구성 요소로 표시할지 또는 전체 전용 페이지로 표시할지를 결정합니다.
- 컨시어지가 표시되어야 하는 도메인 및 페이지 경로를 식별합니다.

## 데이터 스트림 구성

데이터 스트림은 방문자와 컨시어지의 상호 작용으로 생성된 활동 데이터의 대상입니다. 이러한 상호 작용의 예로는 클릭, 양식 제출, 예약된 회의 및 라이브 채팅이 있습니다. 데이터 스트림을 사용하면 나중에 Analytics에서 이 활동을 볼 수 있습니다.

이 절차의 일부로 데이터 스트림을 작성할 필요는 없습니다. 아이디만 있으면 됩니다.

### 데이터 스트림 ID 얻기

IT 또는 분석 팀에 데이터 스트림 ID를 요청합니다. ID는 Adobe Experience Platform에서 **데이터 수집** > **데이터 스트림**&#x200B;에 있습니다.

### 데이터 스트림 구성 추가

1. 데이터 스트림 ID를 준비하십시오.
1. Brand Concierge 배포 섹션에서 **구성 추가**&#x200B;를 선택합니다.
1. 데이터 스트림 ID를 붙여넣습니다.
1. 구성을 저장합니다.
1. 구성이 저장되면 적절한 설치 옵션을 선택합니다.
   - **구성 요소 설치:** 웹 사이트 팀이 웹 사이트의 특정 위치에 배치하는 코드 조각을 사용합니다.
   - **전체 페이지 설치:** 전용 컨시어지 랜딩 페이지에 대해 호스팅할 준비가 된 전체 페이지를 사용합니다.
1. 웹 사이트 팀에 선택한 스크립트 또는 페이지를 제공합니다.
1. 웹 사이트 팀이 페이지 코드나 태그 관리자를 통해 스크립트를 설치하도록 합니다.

>[!NOTE]
>
>설치는 일반적으로 웹 사이트 팀이 처리하며, 분석 또는 채팅 도구 태그를 추가하는 것과 비슷합니다.

## 표면 구성

스크립트가 설치된 후 표면 구성은 컨시어지가 나타나는 페이지를 제어합니다. 예를 들어 제품 페이지에는 표시되지만 경력 페이지에는 표시되지 않도록 컨시어지를 구성할 수 있습니다.

### 도메인 및 페이지 규칙 추가

1. `blog.example.com`과(와) 같은 도메인을 추가합니다.
1. 도메인의 경로가 일치하는 방식을 선택합니다. 사용 가능한 일치 패턴은 다음과 같습니다.
   - 도메인 아래의 모든 페이지.
   - 지정된 값으로 시작하는 경로입니다.
   - 지정된 값으로 끝나는 경로.
   - 정확한 경로가 일치합니다.
1. 여러 규칙을 결합하여 보다 정확한 페이지 범위를 정의합니다.
1. 서피스 구성을 저장합니다.

## 배포 확인

웹 사이트 팀이 스크립트를 설치하고 표면 규칙을 저장한 후 다음을 확인합니다.

- 스크립트는 의도한 웹 사이트 페이지에 있습니다.
- 컨시어지는 구성된 규칙이 적용되는 페이지에만 표시됩니다.
- 컨시어지는 제외된 페이지에 나타나지 않습니다.
- 방문자 상호 작용은 구성된 데이터스트림에 대한 활동 데이터를 생성합니다.

>[!TIP]
>
>포함된 페이지와 제외된 페이지를 모두 테스트합니다. 이는 컨시어지가 광범위하게 사용가능해지기 전에 표면 규칙이 의도한 대로 작동하고 있음을 확인합니다.

## 미해결 질문 및 범위 참고 사항

출처 자재는 다음 상세내역을 정의하지 않습니다.

- 데이터스트림으로 전송된 전체 이벤트 유형 표준 목록입니다. 제공된 예로는 클릭 수, 양식 제출, 예약된 회의 및 라이브 채팅이 포함되지만 전체 목록은 엔지니어링으로 확인해야 합니다.
- 체험판 고객과 유료 고객 간에 데이터 스트림 구성이 다른지 여부.
- 데이터스트림 활동이 표시되는 특정 분석 제품. 소스 자료에서는 이를 &quot;Analytics&quot;로만 참조합니다.

이러한 질문은 별도의 원격 분석 요구 사항과 겹칠 수 있으므로 배포 지침을 확정적 참조로 게시하기 전에 해당 엔지니어링 또는 제품 팀과 해결해야 합니다.
