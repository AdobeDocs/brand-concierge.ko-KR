# Brand Concierge 개요

Brand Concierge은 기업과 브랜드가 고객 대면 표면(웹 사이트, 모바일 앱 및 기타 디지털 속성)에서 개인화된 대화 경험을 시작할 수 있도록 하는 아젠틱 플랫폼입니다. 모든 대화는 브랜드 자체의 콘텐츠와 가드레일에 기반하며, 통합은 이러한 대화의 통찰력이 Marketo Engage과 같은 나머지 브랜드 생태계로 흘러가게 합니다.

## 주요 구성 요소

Brand Concierge 배포에는 두 가지 주요 부분이 있습니다.

| 조각 | 정의 |
|---|---|
| **방문자 경험** | 웹 사이트 또는 모바일 앱과 같이 브랜드 이미지를 갖춘 표면으로, 방문자가 컨시어지와 소통하고 실시간으로 응답을 얻을 수 있습니다. |
| **작성기** | 컨시어지 경험을 디자인하고 컨시어지, 통합, 구성, 평가, 배포 및 분석을 관리하는 데 사용되는 전문가 인터페이스입니다. |

## 이 안내서에서 다루는 작성기 모듈

Composer 내에서 주요 모듈(및 이 안내서에서 다루는 위치)은 다음과 같습니다.

- 사용자 관리(섹션 3)
- 여러 분야에 걸쳐 공유되는 지식 소스 생성 및 관리(섹션 4)
- 컨시어지 관리: 통합, 기술, 컨시어지 지침, 톤 및 음성, 비주얼 스타일 및 채팅 구성 요소(5절)
- 평가(섹션 6)
- 배포(섹션 7)
- Go-Live 체크리스트(섹션 8)
- Analytics(섹션 9)

## 조각이 연결되는 방식

지식 소스(콘텐츠)는 통합(연결)으로 쿼리되며, 이 통합(연결)은 스킬(비헤이비어)에 의해 호출되고 방문자가 상호 작용하는 모든 컨시어지(전체 경험)에 래핑됩니다.

## 용어집

이 용어는 Composer 인터페이스 전체에 나타납니다.

| 용어 | 정의 |
|---|---|
| **컨시어지** | AI 채팅 경험 자체: 브랜드, 웹 사이트 또는 사용 사례당 하나. 하나의 계정에 여러 개의 계정이 있을 수 있습니다. |
| **작성기** | 웹 사이트 방문자가 보는 것과 구별되는 컨시어지를 구축하고 관리하는 데 사용되는 인터페이스입니다. |
| **기술 자료 원본** | 웹 사이트 페이지나 제품 목록과 같은 질문에 답변할 때 컨시어지가 사용할 수 있는 콘텐츠입니다. 콘시어지는 대답할 것이 없다. |
| **통합** | 웹 사이트 콘텐츠 또는 라이브 제품 카탈로그와 같은 정보를 검색할 수 있는 시스템에 대한 연결입니다. |
| **스킬** | 일반적인 질문에 대한 답변, 제품 비교 또는 회의 예약과 같이 컨시어지가 수행할 수 있는 특정 기능. 스킬은 하나 이상의 통합을 사용하여 해당 기능을 수행합니다. |
| **가드레일** | 경쟁업체 또는 법률 조언과 같이 컨시어지가 하거나 논의해서는 안 되는 작업을 정의하는 규칙입니다. |
| **평가** | 예상 답변과 쌍을 이루는 샘플 질문으로 구성된 구조화된 테스트로, 컨시어지 성능을 평가하는 데 사용됩니다. |
| **데이터 스트림 ID** | Adobe 시스템 내에서 방문자 활동 데이터가 전송되는 위치를 지정하는 기술 식별자입니다. IT 또는 분석 팀에서 제공합니다. |
| **샌드박스** | 조직 내의 격리된 작업 영역입니다. 조직은 두 개 이상을 가질 수 있습니다. 각 조직은 여러 개의 초안을 가질 수 있습니다. |
| **IMS 조직** | Adobe의 조직 전체 계정 용어입니다. |
| **MCP**(예: Commerce MCP) | IT 또는 상거래 팀에서 제공한 코드 또는 키를 사용하여 구성된 라이브 제품 카탈로그와 같은 특정 시스템에 대한 Adobe 관리 커넥터입니다. |
| **CJA(Customer Journey Analytics)** | Adobe의 분석 제품. Brand Concierge은 추가 설정 없이 여기에서 스타터 대시보드를 자동으로 프로비저닝합니다. |

>[!NOTE]
>
>마케터는 일반적으로 섹션 3, *사용자 및 액세스 관리*&#x200B;를 완전히 건너뛰고(IT 부서의 누군가가 한 번 완료) 섹션 4, *지식 소스*&#x200B;에서 시작할 수 있습니다. 새로운 팀원을 설정할 때만 섹션 3으로 돌아갑니다.
