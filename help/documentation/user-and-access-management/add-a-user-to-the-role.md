# Brand Concierge 역할에 사용자 추가

**Brand Concierge 관리** 권한이 포함된 역할에 사용자를 할당하십시오. 또한 사용자는 Adobe Experience Platform을 사용하려면 먼저 Brand Concierge 조직에 액세스할 수 있어야 합니다.

## 사전 요구 사항

* 사용자가 Adobe Experience Platform 조직에 추가되었습니다. 자세한 내용은 &#39;조직에 사용자 추가&#39;(LINK)를 참조하십시오.
* **Brand Concierge 관리** 권한이 포함된 역할을 만들었습니다. 자세한 내용은 &#39;Brand Concierge 권한으로 역할 만들기&#39;(LINK)를 참조하십시오.

## 역할의 사용자 추가

1. Adobe Experience Platform에서 **권한**&#x200B;을 엽니다.
2. Brand Concierge 액세스를 위해 만든 역할을 엽니다.
3. **사용자** 탭을 선택합니다.
4. 사용자를 검색하고 역할에 사용자를 추가합니다.
5. 메시지가 표시되면 할당을 저장합니다.

## 사용자 레코드에서 역할 추가

사용자의 레코드에서 역할을 할당할 수도 있습니다.

1. 사용자 레코드를 엽니다.
2. **역할 추가**&#x200B;를 선택합니다.
3. Brand Concierge 역할을 검색합니다.
4. 역할을 선택하고 할당을 저장합니다.

## 액세스 확인

조직 초대 및 역할 할당이 모두 완료되면 사용자는 다음을 수행할 수 있습니다.

* `experienceplatform.adobe.com`에 로그인합니다.
* 액세스할 수 있는 조직을 봅니다.
* **Brand Concierge**&#x200B;을(를) 엽니다.
* 역할을 통해 부여된 샌드박스 또는 샌드박스를 봅니다.

사용자는 샌드박스 내에서 여러 개의 개념을 만들 수 있습니다.
