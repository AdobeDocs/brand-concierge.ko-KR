# 조직에 사용자 추가

사용자가 Brand Concierge에 액세스하려면 Adobe Admin Console에서 Adobe Experience Platform 조직에 사용자를 추가하십시오.

## 사전 요구 사항

* 조직에 대한 관리자 액세스 권한이 있어야 합니다.
* 사용자는 개별적으로 또는 대량 사용자 업로드를 통해 추가할 수 있어야 합니다.

## 사용자 추가

1. **Admin Console**(으)로 이동합니다.
2. **관리**&#x200B;를 선택하거나 **사용자**(으)로 이동하세요.
3. 사용자를 개별적으로 추가하거나 일괄 업로드를 통해 여러 사용자를 추가하십시오.
4. 사용자가 아직 조직에 없는 경우 메시지가 표시되면 옵션을 선택하여 사용자를 새 사용자로 추가합니다.
5. 제품 프로필 선택:

   * **Adobe Experience Platform**
   * 기본 사용자 프로필

6. **저장**&#x200B;을 선택합니다.

사용자는 조직에 대한 액세스를 확인하는 이메일 초대를 받습니다.

>[!IMPORTANT]
>
>조직 초대는 사용자에게 조직에 대한 액세스 권한을 부여하지만 Brand Concierge에 대한 액세스 권한은 부여하지 않습니다. Brand Concierge 액세스를 제공하려면 &#39;Brand Concierge 권한으로 역할 만들기&#39;(LINK)에 설명된 대로 Brand Concierge 권한이 있는 역할을 만들고 할당합니다.

## 다음 단계

사용자가 조직에 추가되면 **Brand Concierge 관리** 권한이 있는 역할을 만들고 사용자를 해당 역할에 할당하십시오.
